# SmartAgroSense
Agrosense Farmer App: AI-driven mobile solution for precision farming. Optimizes yields using IoT sensor data, satellite imagery (NDVI), and predictive diagnostics for resource scheduling and pest

**TO ACCESS THE CODE FILES { DUE TO LARGE FILE SPACE AND EASY ACCESIBILITY }**
- Kindly visit the **Tags** section
- Select the **v1.0 Tag** option
- the Public Releases contain the zip file 

HOW TO START THE PRODUCT : (Incorported in the video prototype denonstration)
- launch and host in on the local server
- --> Open Terminal in VS Code (or any IDE)
- npm install
- cd AgroSense (Change directory)
- npm run dev
- --> localhost:5000 starts on your default browser
- Explore our **Prototype Beta** version.
